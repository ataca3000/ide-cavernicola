# Plugin de Visión por Computadora (Vision)

## 📌 ¿Qué colocar aquí si lo necesitas?
> Coloca aquí modelos de detección de objetos, reconocimiento de piezas mecánicas en chatarra o inspección visual de soldaduras.

### 📋 Formato sugerido:
- **Estructura recomendada:** .py usando OpenCV, YOLO o modelos multimodales.
- **Autoría:** Mantener atribución a **Luis Felipe Durán Salinas / Brecha Soluciones DS**.
